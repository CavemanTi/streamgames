Adding it

  1. Add a Browser source and paste that URL.
  2. Set it to 1920 × 1080. Scale it down in the scene if you want it smaller.
  3. Untick "Shutdown source when not visible." Otherwise switching scenes drops the chat connection.
  4. Type !drop in your own chat to check it.
Changing settings later means coming back here and pasting a new URL. If you're on OBS Studio you can instead add the control panel as a custom browser dock and change things live.
