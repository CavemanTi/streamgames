StreamGames

Interactive chat games for Kick streamers. Each one is a single page you point OBS at — it talks to your chat directly, keeps its own scores, and never checks in with anybody.

Setting it up

  1. In OBS, add a Browser source and paste the browser source URL. Set it to 1920×1080 and tick Shutdown source when not visible off.
  2. Open View → Docks → Custom Browser Docks, name it Plinko and paste the control dock URL.
  3. In the dock, enter your chatroom ID. On your channel page, open devtools → Network → WS, and look for chatrooms.NNNNN.v2.
  4. Type !drop in your own chat to confirm it's connected.
Why it works this way. Everything runs inside OBS on your own machine. There's no licence check and no account, so there's no server that can go down and take your widget with it. If this project ever stops being maintained, the files keep working — and the source is public, so anyone can host their own copy.
